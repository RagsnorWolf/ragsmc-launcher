# 🐺 RagsMC Launcher

**Launcher de Minecraft desarrollado por RagsnorWolf.**

RagsMC Launcher busca ofrecer una forma sencilla, moderna y personalizable de gestionar y ejecutar Minecraft desde un solo lugar.

## ✨ Características

* 🎨 Interfaz moderna y personalizable.
* ⚡ Diseñado para ser sencillo y rápido de utilizar.
* 🧩 Gestión de versiones de Minecraft.
* ⚙️ Opciones de configuración.
* 🐺 Diseño propio de RagsMC.
* 🔓 Código fuente disponible públicamente.
* 🔄 Actualizaciones y mejoras continuas.

---

## 📥 Instalación

1. Entrá a [Releases](https://github.com/RagsnorWolf/ragsmc-launcher/releases).
2. Descargá la última versión disponible.
3. Ejecutá el instalador.
4. Seguí las instrucciones de instalación.
5. Abrí RagsMC Launcher y configurá tu instalación.

> 💡 También podés descargarlo desde la [página oficial](https://ragslaunchermc.dpdns.org/).

---

## 💻 Requisitos

* Windows 10 / Windows 11
* Conexión a Internet
* Espacio suficiente para Minecraft y sus archivos
* Los requisitos de hardware dependen de la versión de Minecraft que quieras ejecutar.
